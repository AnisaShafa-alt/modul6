3. Jelaskan secara singkat apa itu jQuery dan kegunaannya!
   Jawaban:
   yaitu library JavaScript yang dirancang untuk mempermudah penulisan kode JavaScript
   jQuery dipakai untuk memanipulasi elemen HTML, menangani event, membuat animasi, serta melakukan komunikasi dengan server memakai AJAX dengan kode yang lebih sederhana
5. Jelaskan perbedaan JavaScript dan jQuery!
   Jawaban:
   - pengertian: JavaScript yaitu bahasa pemrograman yang dipakai untuk membuat halaman web interaktif, sedangkan jQuery yaitu library JavaScript yang mempermudah penulisan kode
   - penulisan kode: JavaScript terkadang membutuhkan kode yang lebih panjang untuk memanipulasi elemen HTML, sedangkan jQuery menyediakan sintaks yang lebih singkat & sederhana
   - manipulasi HTML: JavaScript memakai DOM API, seperti document.getElementById(), sedangkan jQuery memakai selector & method, seperti $("#kotak").hide()
   - penanganan event: JavaScript memakai method seperti addEventListener(), sedangkan jQuery dapat memakai method seperti .click() or .on()
   - ketergantungan: JavaScript dapat digunakan tanpa library tambahan, sedangkan jQuery membutuhkan library jQuery agar fungsi-fungsinya agar bisa digunakan
